# WorkBuddy Auto Claim

**在自己的 Mac 上，自动检查并领取 WorkBuddy「Buddy 加油站」每日积分；支持锁屏后台运行和故障提醒。**

这是从实际使用中整理出来的社区脚本，包含源码、安装工具、离线测试，以及给没有上下文的 AI 的接手指南。它不调用 AI 模型，日常运行不消耗模型额度。

当前公开版本：`v0.1.0`，实验性版本。2026-10-13 已在一台 Intel Mac 上验证新版加密登录、跨日定时领取及锁屏领取。其他设备与未来客户端版本需要重新验证。

## 解决什么问题

每天手动打开应用领奖容易忘记；模拟鼠标点击依赖窗口位置，锁屏时也可能失效。本程序通过本人已经登录的 WorkBuddy 状态，直接查询官方服务器，明确未领取才发请求，随后核实结果。macOS 自己负责定时启动，关闭终端或 AI 聊天窗口后仍能运行。

曾遇到客户端更新后凭证变为加密格式，自动领取连续失败，而且旧提醒没有覆盖这个错误。公开版包含这次兼容修复，也覆盖格式变化等永久故障提醒。这说明程序仍需要维护，不能保证安装后永久无需检查。

## 可以做到什么程度

| 能力 | 行为与边界 | 默认 |
| --- | --- | --- |
| 每日积分 | 北京时间 06:30 起检查；活动开放且未领才领取，再查服务端。积分数由活动决定，不硬写到账数量 | 开启 |
| 锁屏运行 | 电脑已登录、唤醒、联网时，可以在锁屏状态运行 | 支持，需本机验收 |
| 补查 | 系统每五分钟触发，恢复联网/唤醒后重新检查；不补领已经过去的日期 | 开启 |
| 宠物旅行 | 闲置且有名额时派往本人核实的免费地点；回程领取礼物；地点配置改变会停止 | 另行授权 |
| 任务奖励 | 仅领取服务端明确已达标且未锁定的奖励，再核实 claimed | 另行授权 |
| 本机通知 | 登录错误、兼容错误等提醒；连续网络失败满一小时才提醒；同日最多成功提交一条 | 安装通知应用并授权后生效 |
| 去重 | 写请求前保存意图；未知结果先回查，无法确认时停止重复请求 | 开启 |
| 账号隔离 | 当前账号与已有运行状态不符时停止，要求人工检查 | 开启 |

正常完成时保持安静。不会自动接受新任务、刷对话、抽奖、开盲盒、兑换、补登或消费积分/能量。

## 使用条件

- macOS 13 或以上；已安装 WorkBuddy，并用自己的账号登录。
- Python 3.10 或以上；开发者环境实际验证为 Python 3.12 / macOS 13 Intel。
- 编译通知应用需要 Apple Command Line Tools（`clang`）。Node.js 18+ 只用于可选的 Node 离线测试；正式运行的加密兼容使用 WorkBuddy 自带 Electron。
- 电脑必须已登录、保持唤醒并联网。锁屏可以，睡眠/关机不能运行；本项目不修改电源设置或自动解锁。
- 日历触发的 06:30 按系统时区解释；业务日期和时间门禁固定为北京时间。建议系统使用北京时间；其他时区靠五分钟补查，可能在北京时间 06:30 后数分钟执行。

## 开始使用

```bash
git clone https://github.com/maureen2215-ai/workbuddy-auto-claim-public.git
cd workbuddy-auto-claim-public
python3 -m unittest discover -s tests
node --test tests/test_desktop_session.cjs  # 已安装 Node 时执行
python3 configure.py                       # 只预览
```

接下来按 [安装与首次验收](docs/INSTALL.md) 授权本机登录状态、只读验证、编译通知应用，再安装定时任务。**下载或克隆不会安装，不会自动领取；`--install` 会启用实际领取。**

不熟悉命令也可以把下面一段交给你自己的 AI。它应先给你具体检查结果，获得安装范围授权后再执行：

```text
请帮我安装这个仓库：
https://github.com/maureen2215-ai/workbuddy-auto-claim-public
先读 AGENTS.md、README.md、docs/AI_HANDOFF.md 和 docs/INSTALL.md。
先只读检查我的 Mac、Python、WorkBuddy 版本、登录格式兼容性及是否已有同名定时任务，
运行离线测试，报告安装会改哪些本机文件、会执行哪些账号操作。
首次先只启用每日积分；旅行和任务奖励另问我。
凭证留在我的电脑，不要让我复制 token，不上传登录文件、运行状态或日志。
请先报告并等我确认安装。安装后按验收清单核实实际运行，
不要把测试通过、进程退出成功或 HTTP 200 说成积分已到账。
```

## 日常使用

```bash
python3 manage.py status          # 本机检查，不请求领取
python3 src/background.py diagnose # 官方状态只读查询；不允许奖励写接口
python3 manage.py pause --apply   # 暂停后续任务，保留所有记录
python3 manage.py resume --apply  # 恢复，可能处理尚未领取的奖励
```

收到登录提醒时，在 WorkBuddy 中完成登录；只是打开窗口不一定续期。收到兼容/其他故障提醒时，先检查状态并让 AI 按 [排错与遗留问题](docs/KNOWN_ISSUES.md) 处理。每日积分可先手动领取，程序会尊重服务端已领状态。

## 这是什么接口

程序使用客户端的官方服务接口，并不是腾讯正式提供的“自动签到开放 API”。当前公开 Open API 文档没有列出本项目的签到和旅行接口。它们可能随客户端更新而改变，社区脚本也没有官方支持或稳定性承诺。[官方 Open API 文档](https://open.workbuddy.cn/docs/openapi)

固定目标为 `https://copilot.tencent.com`，携带本人已有登录状态；拒绝重定向和非白名单操作。标准加密 accessToken 通过已安装 WorkBuddy 自带组件在本机进程中读取；密钥与令牌不落盘、不写日志、不放进命令参数或环境变量。未知加密方案停止并提醒。
